# FRAME — Motion Studio

Interactive image corridor, GSAP scroll animation and Three.js sculpture.

## Local development

Requires Node.js 22.13+ and pnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

## Production

```sh
pnpm build
pnpm start
```

Import this repository into Vercel. Framework: Next.js. No environment variables required. Images are bundled under `public/images/`.
